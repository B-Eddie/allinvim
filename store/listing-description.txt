Stop reaching for the mouse. AllinVim brings Vim to the entire web: one extension that navigates every page like Vim and edits every text surface like Vim — text fields, Google Docs, and code editors — with a handoff between the two you never feel.

NAVIGATE EVERY PAGE
• hjkl scrolling, gg / G, zt / zz / zb
• f / F link hints — follow any link without touching the mouse
• o / O Vomnibar: fuzzy-find open tabs, history, bookmarks, and the web
• Tab control (J / K, x, X, t), marks (m / `), find mode (/), history ([[ / ]])
• Custom key mappings, per-site exclusion rules, new-tab options

EDIT EVERY TEXT SURFACE
• Full Vim grammar in any textarea, input, or contenteditable: motions (w b e 0 ^ $ gg G f F t T), operators (d c y) + text objects (iw, i", a(, ip…), visual modes, . repeat, marks
• Google Docs canvas editing via synthetic keys — boots in NORMAL, Esc leaves insert, block caret in normal/visual modes
• CodeMirror, Monaco, ProseMirror and friends edit in an exact overlay surface, then commit once — no desync, ever
• One capture-phase router decides the owner per keystroke: editor keys never leak into page scroll, page keys never type into your buffer. Visible overlays (hints, Vomnibar, help) always win.

YOURS
• Six dark themes (Trigger, Catppuccin Mocha, Dracula, Gruvbox Dark, Tokyo Night, Nord), custom link-hint CSS, adjustable mode indicator
• Settings sync across your devices via Chrome sync; backups export/import as JSON
• Fast by design: document_start injection, inlined config (no fetch on web pages, strict-CSP safe), zero polling

PRIVACY
AllinVim works fully offline. Your settings sync through your own Google account; history and bookmarks are read locally on-device only to power Vomnibar suggestions. No analytics, no tracking, no data sold or shared. Full policy linked in the Privacy policy field of this listing.

Built on the proven philc/vimium navigation engine (MIT), unified with Vim-For-Textarea and Vim-For-Docs style editing layers. Press ? on any page for the full binding list.
